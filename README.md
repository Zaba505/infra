# infra

infra defines a self-hosted application platform: the place my own capabilities
run by default, so that none of them depends on a vendor's hosting product. It
spans a public cloud and my home lab, is run by one operator, and can be stood up
from nothing, from this repository, in at most 60 minutes.

infra is being rebuilt from scratch. The
[charter](https://github.com/Zaba505/infra/discussions/970) says what the
platform is, the rules every change is held to, and the order its parts come back
in. The [docs site](https://zaba505.dev/infra/) documents each part as it lands.
